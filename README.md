# Tsioukis Ioannis Digital Card

Standalone static digital business card for Ioannis Tsioukis.

## Files

- `index.html`: main business card page
- `Static/assets/ioannis-tsioukis.vcf`: downloadable contact card
- `Static/assets/Tsioukis.png`: QR code image

## Usage

Open `info.html` in a browser.
